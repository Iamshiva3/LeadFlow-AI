# LeadFlow AI – Automated Lead Management System

## Project Overview
LeadFlow AI is an AI-powered lead management automation system. It captures customer enquiries through Google Forms, generates personalized email responses using Google's Gemini API, sends emails through Gmail, and records the results in Google Sheets.

## Technologies Used
- Google Forms
- Google Sheets
- Google Apps Script
- Google Gemini API
- Gmail

## Workflow
1. A customer submits an enquiry through Google Forms.
2. The form response is stored in Google Sheets.
3. Google Apps Script detects the new submission.
4. Gemini AI generates a personalized email subject and response.
5. Gmail sends the response when the customer has given consent.
6. The CRM sheet records the generated response, email status, and processing time.

## Main Features
- Automated lead capture
- AI-generated personalized email responses
- Automated email delivery with consent checking
- CRM logging in Google Sheets
- Error handling and processing status tracking
